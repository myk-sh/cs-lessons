# IGCSE 0478 AI exam audit

Reviewed 21 Paper 1 question papers and their 21 published Cambridge mark schemes: Feb/Mar variant 12 and May/June and Oct/Nov variants 11–13 for each of 2023, 2024 and 2025. 18 papers contain relevant AI parts; 29 individual AI parts were identified. The lesson practises 20 adapted past-paper parts, retaining their published mark allocations. All seven observed question families are taught.

This is coverage of the audited papers, not a prediction or guarantee of future questions. Whole source PDFs are kept in the local research workspace, not republished. Questions and marking points in the lesson are paraphrased.

## Observed question families and lesson response

| Family | What students practise |
| --- | --- |
| Definition / characteristics | Distinct creditworthy features; avoid repeating features already supplied. Task 2. |
| Component identification | All four components; exclude named components; reject hardware/security distractors. Task 3. |
| Component roles / cloze | Facts vs rules vs applying rules; interface used for input/output; repeated terms allowed where the question says so. Task 3. |
| Expert-system operation | Question selection from prior answers → facts/rules → diagnosis; separate full workflow from processing-only questions. Task 4. |
| ML recognition / capabilities | AI subset, training, patterns, automatic adaptation, data/process changes and feedback. Tasks 2 and 5. |
| Navigation / robot improvement | Specific route/obstacle experience → stored successes/failures → changed later actions. Task 5 and Task 6. |
| Contextual ML | Feedback for search; trends for weather; voice patterns/accents; player-action patterns. Task 6. |

## Important marking distinctions

- 2024 May/June 12 Q10(a) credits the simulation idea as one point, with another AI feature for the two-mark answer. 2025 Oct/Nov 13 Q6(a) requires any three distinct features. Do not award arbitrary marks for isolated words in a definition.
- 2025 Feb/Mar 12 Q6(a) gives learning in the question: it cannot be one of the three other characteristics. The scheme lists data collection and rules separately.
- 2025 May/June 12 Q5(a) asks how the diagnosis is decided after input and before output: focus on the inference engine, adaptive questioning and facts/rules.
- 2024 May/June 12 Q10(b) accepts explanation-system reasoning as an additional route to credit. Teach it as supporting functionality; the four core components remain interface, knowledge base, rule base and inference engine.
- 2023 Oct/Nov 13 Q10(a) accepts the rule base and knowledge base in either order for the apply-to pair.
- 2023 Oct/Nov 13 Q10(b) accepts supervised/unsupervised training as alternatives. These are explained briefly; neural-network layers and the narrow/general/strong taxonomy are not required.
- A conventional fixed-rule expert system need not learn, but actual papers explicitly give some expert systems ML capabilities. Avoid presenting the approaches as mutually exclusive.

## Delivery and assessment

Core 60-minute lesson: use selected Task 1 recall parts, Tasks 2 and 4, selected Task 3 role/cloze questions and Task 5 navigation. Set remaining component questions and Task 6 as follow-up practice; use the full pack across a second period if required. The answer key has model answers, accepted alternatives, mark ceilings and pitfalls for every part. Task 1 is original retrieval practice with suggested marks; Tasks 2–6 use verified official allocations.
